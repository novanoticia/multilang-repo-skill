# 会话记录

用于在中断或压缩后继续工作的工作记忆（R6）。它不是权威来源：许可只来自用户。建议存放位置：仓库之外，或在仓库内通过 `.git/info/exclude` 排除的路径中，绝不放进包里。

## 许可（R13）

原话引用，不转述。有效期：`una vez`（一次）、`esta tarea`（本任务）、`esta sesión`（本会话）或 `hasta que se
revoque`（直到撤销）。状态：`vigente`（有效）、`usado`（已使用）、`vencido`（已过期）或 `revocado`（已撤销）。
