# 带有外部数据的新内容（C1–C9）

与 [contenido] 一起阅读：当工作引入有关外部世界的陈述时（版本与兼容性、平台限制、官方名称、规范、日期、数字、临床或法律数据）。

**C1 先定形式，后谈数量。** 默认提供来源索引（每项是什么、由谁发布、在哪里、其状态，以及何时应引用它），而不是复制第三方文本。只有在用户要求且许可允许时才复制。如果因缺少来源而拒绝某项数据，索引就是你提供的替代方案。如果没有网络而只能凭记忆说出来源，就在回答和待办事项中把它们列为 `no-comprobado`（未核实），并写明所需的域名（C8），以便用户核查；在核实之前（R10），它们不进入仓库的索引。

**C2 先用一手来源。** 即发出该数据的机构或作者的发布物、制造商的官方文档或官方登记册。搜索结果或摘要属于二手来源；如果可以，就打开一手来源。

**C3 内容本身标注来源等级。** `oficial`、`segunda-mano`（二手）或 `no-comprobado`，采用 R10 的录入规则。区分 `no-aplica`（该数据在该语言或上下文中不存在）与 `no-comprobado`（可能存在，但你没有找到）。

**C4 时效。** `vigente`、`sustituido`、`retirado`、`anulado`、`obsoleto` 或 `no comprobado`，并附查阅日期。绝不要在未经确认的情况下断言其有效。已撤回的数据保持为已撤回，并注明不要把它当作有效数据使用。

**C5 内容验证。** 必填字段、等级和时效的封闭取值、所有带文本的数据必须有来源、唯一的标识符，以及指令中指向索引的引用。在 S 规模下，一份核对清单即可；在 M 和 L 规模下，则需要一个带有蓄意破坏测试的脚本（P7）。

**C6 来源之间的分歧。** 按各来源的分量如实呈现。不要把仅由一个孤立来源支持、而与多个一致来源相左的内容当作悬而未决的疑问，反过来也一样。把可信度平均分给不对等的来源是虚假的平衡。

**C7 自动发现不是事实。** 在因为某个机器人、另一个模型或没有来源的人这样说就修改某项数据之前，先核查一手来源。如果无法核查，就把断言降到你确实知道的范围，并留下记录。

**C8 未核实的内容进入待办事项**（R10），并注明缺少的来源和所需的网络域名。对于 [alto-riesgo]，由专业人员在任何使用之前审阅该内容，输出本身也要说明这一点。

**C9 严谨程度与风险相称。** 对低风险数据（某工具的最低版本），官方文档加查阅日期即可。对高风险数据（剂量、法定期限、安全限值），则需要官方一手来源、不得使用任何凭记忆的数据、查阅日期，以及专业人员审阅。绝不要编造数据或引用：每条引用都必须可以找回（标题、发布方、URL 或标识符、日期）。删除不指向可识别来源的引文标记，并用文字表达不确定性，而不是隐藏它。
