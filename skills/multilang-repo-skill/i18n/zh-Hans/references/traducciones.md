# 翻译与高风险（T1–T7、D26）

在阶段 5 阅读本文，并且只要 [alto-riesgo] 处于启用状态就阅读。

**T1 翻译前先定术语表。** 确定术语和称呼方式（如西班牙语的 `tú` 或 `usted`，法语的 `tu` 或 `vous`），并始终保持一致。按规模相称地用一项测试来守住它，并记录所选的称呼方式。

**T2 保留非散文内容。** 占位符、emoji、格式和机器契约保持不变。不要翻译产品名称、命令、模式、选项、路径或代码（B1）；只用于显示的封闭词汇值（B2）在散文中翻译，如果用户需要键入它，则在旁边保留字面量。遵循每种语言的排版规范（引号 «»，法语中某些标点前的空格），并记下所做的选择，因为母语审阅者可能更喜欢另一种。

**T3 相近语言。** 如果你的译文与原文相同且验证器已指出，就寻找该语言自己的表达；不要为了通过而添加例外。只有在文本有正当理由时（符号、代码、专有名称）才将其标为不变，并记下理由。

**T4 官方名称（G）。** 从每种语言的官方来源复制，按表头而不是按位置读取列，并检查它没有返回错误的语言。如果没有官方版本，则使用代码加上可得的官方名称。如果来源无法访问，则适用 R10（`segunda-mano`（二手）或 `no-comprobado`（未核实），并列入待办事项）。

**T5 如实标注状态。** 由 AI 翻译的内容保持为 `borrador-ia`（AI 草稿）（D12）：在仓库中和交付时说明（给用户的报告；运行时输出中的警告在阶段 2 决定，D22），并且不要将其呈现为已审阅。由另一个模型审查并不会使它变成已审阅。不要把经过审阅的语言质量归于只经过 AI 的内容。

**T6 把握较低的语言。** 说明你对哪种语言的判断把握较低及原因。你无法判断的语言，以 `experimental`（实验性）交付（这意味着 `borrador-ia`，D12），并附带加强的警告（例如双语），必须有母语审阅，并且只有在用户了解风险后授权时才可交付。

**T7 模型自由文本（H）。** 它放不进目录。指示模型用所选语言撰写，并在文档中声明它未经审阅。

## [alto-riesgo]

**D26 风险短语。** 逐一识别它们（`riesgo: alto`）：对不可逆操作的确认、职业界限、安全警告、剂量、期限和义务。翻译时不要“改进”它们。注意会颠倒含义的结构（用是或否回答的否定问句、双重否定）。对于你无法判断的语言，如果重新表述会改变与原文的契约，就将它们标记为风险，而不是重新表述。

本模块的要求：
- 在任何专业用途之前，须有两次不同的人工审阅：内容由该领域的专家审阅（C8），风险短语的翻译由母语者审阅（适用时还须是专家）。一种不能替代另一种。如果尚无审阅，仓库和交付中应写“待人工审阅”，而不是将工作视为已完成。
- commit 或 PR 标记为需要人工审阅 diff，从 `riesgo: alto` 的键开始。
- 场景（P13）用于检查每种语言中风险短语的含义，级别为 `simulada`（模拟），且不替代人工审阅。
